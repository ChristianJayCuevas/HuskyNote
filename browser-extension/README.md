# HuskyNote Browser Extension

Manifest V3 Google Chrome extension for Google Meet and browser tab audio capture assistance.

## Installation

1. Open Google Chrome and go to `chrome://extensions`.
2. Toggle on "Developer mode" in the top-right corner.
3. Click "Load unpacked" and select this `browser-extension` folder.
4. When you open a Google Meet session, the HuskyNote overlay will appear with a one-click connection button.
